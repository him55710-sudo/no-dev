# 풀어봄 — 코드가, 말이 되다

**제품 우선 개발:** [상세 완성 계획](docs/PRODUCT_COMPLETION.md) · [언어별 지원·검증 표](docs/LANGUAGE_SUPPORT.md) · [에이전트 작업 기록](docs/AGENT_WORKLOG.md). 0.7 개발 소스에 선택형 [Ollama 로컬 설명·수정](docs/LOCAL_AI.md)을 추가했습니다. 실제 Python 프로젝트 검증과, 성능이 느려져 채택하지 않은 제안도 공개합니다. 공개 0.6.0 설치본과 브라우저 데모에는 로컬 AI가 없습니다.

**[30초 소개 영상](https://him55710-sudo.github.io/pureobom/demo.html?lang=ko)** — 원문 → 설명 → 변경안 → 주문별 비교 → 적용 → 되돌리기를 실제 공개 화면으로 보여줍니다. 한국어·영어 자막과 텍스트 설명을 제공합니다. [MP4 받기](https://him55710-sudo.github.io/pureobom/media/pureobom-30s.mp4).

**0.6.0 공개 시제품:** 낯선 코드 이름에 내 용어를 붙이고, 규칙을 바꿔 최대 12개 입력의 전후 결과를 비교합니다. MIT 라이선스로 공개합니다. [설치 없이 체험](https://him55710-sudo.github.io/pureobom/?demo=shipping&lang=ko) · [설치 파일과 소스](https://github.com/him55710-sudo/pureobom/releases) · [검증 기록](docs/RELEASE_VALIDATION.md). Marketplace 게시와 실제 수요 검증은 아직 완료하지 않았습니다.

AI가 만든 코딩 파일을 비개발자가 읽을 수 있는 문장·구조·연결 지도·표로 보고, 값과 조건을 수정한 뒤 실제 코드의 차이와 결과를 확인하는 **로컬 시제품**입니다.

설치된 Go SDK로 [Go 구문·여러 반환값·defer와 원문 값](docs/GO_SOURCE.md)도 읽고 수정합니다. 모델·API 없이 동작하며, Google UUID 프로젝트의 잘못된 값 변경을 실제 테스트가 잡고 undo 후 통과하는 흐름을 확인했습니다. Go 타입·실행 결과 전체를 검증하는 기능은 아닙니다.

## VS Code에서 바로 사용하기 (권장)

**0.7 개발 중:** 로컬 AI와 함께 [실제 프로젝트 검사](docs/PROJECT_CHECKS.md)를 연결했습니다. 기존 테스트·빌드 명령을 확인하고 실행하면 종료 코드와 파일 변경 여부가 표시됩니다. 공개 안정 버전 0.6.0과 브라우저 데모에는 이 기능이 없습니다.

[변경 전후 성능 측정](docs/BENCHMARKS.md)도 추가했습니다. 반복 가능한 process 명령으로 시간·최대 메모리를 7회 측정하고 출력 해시·변동 범위·검사 기록을 함께 확인합니다. Python 3가 필요하며, 느려진 결과도 그대로 표시합니다. 자동으로 최적화 성공을 보증하지 않습니다.

개발 소스에서는 [JSON/JSONC의 실제 데이터](docs/JSON_DATA.md)를 모델 없이 읽고 수정할 수 있습니다. 키 경로·자료형·값·원문 줄을 확인하고 값 하나를 미리보기·적용·되돌립니다. 큰 숫자의 표기와 주석을 보존하며, 데이터가 실제 프로그램에서 어떻게 사용되는지는 별도 확인 대상으로 표시합니다.

로컬 VS Code에서는 [Python 구문·분기·예외와 실제 값](docs/PYTHON_SOURCE.md)도 설치된 Python으로 읽고 수정합니다. 모델·API가 필요 없으며 사용자 코드를 실행하지 않습니다. 외부 프로젝트에서 의도한 잘못된 값 변경으로 테스트가 실패하고 undo 후 복구되는 흐름을 확인했습니다. 전체 Python 구문·타입·실행 결과 분석은 아닙니다.

**0.6 편집기 알림:** VS Code가 보고한 오류·경고를 설명 옆에서 확인합니다. 자주 나오는 TypeScript 오류에는 한국어 뜻풀이를 붙이고 정확한 원문 위치로 연결합니다. [배송비 변경 → 타입 오류 확인 → 되돌리기](docs/EDITOR_REPORTS.md). 알림이 없다고 검사 완료를 뜻하지는 않으며, 브라우저 체험판에는 이 기능이 없습니다.

**0.5.2 정확성 수정:** `try → 오류 처리 → finally 정리`의 표시 순서를 바로잡았습니다. 반환 전에 정리 단계를 거치는 경우도 화면과 설명서에 함께 표시합니다. [검증 내용과 예제](docs/CONTROL_FLOW.md).

**0.5의 새 흐름:** React 화면의 요소·문구·표시 조건·이벤트 속성을 펼쳐 읽고, 문구를 선택해 실제 코드를 바꿉니다. [버튼 문구 바꿔보기](https://him55710-sudo.github.io/pureobom/?demo=interface&lang=ko) · [지원 범위와 한계](docs/INTERFACE.md). VS Code에서는 **풀어봄: React 화면 문구 바꿔보기** 명령으로 시작하세요.

![조건에서 버튼 문구를 찾아 실제 코드를 바꾸는 공개 화면](docs/interface-preview-ko.png)

첫 제품 형태를 **VS Code 확장 기능**으로 구현했습니다. 설치 파일은 배포 묶음의 `pureobom-0.6.0.vsix`입니다. 소스에서 `pnpm extension:build`와 `pnpm extension:package`로 만들 수도 있습니다.

1. VS Code에서 `Ctrl+Shift+X` → 상단 `…` → **VSIX에서 설치…** 로 위 파일을 선택합니다.
2. JavaScript 또는 TypeScript 파일을 열고 `Ctrl+Shift+P` → **풀어봄: 현재 파일 설명 열기**를 실행합니다.
3. 왼쪽 풀어봄 아이콘의 **예제로 시작하기**로 한국어 설명·규칙 변경·코드 비교를 바로 체험할 수 있습니다.

저장 전 내용도 설명에 반영되며, 줄 번호를 누르면 원본 위치로 이동합니다. 변경안은 VS Code 비교 화면에서 확인하고 편집기에 적용합니다. `Ctrl+Z` 실행 취소와 `Ctrl+S` 저장을 사용합니다. 자세한 지원 범위와 사용법은 [확장 기능 안내](extension/README.md), 검증 기록은 [VS Code 검증](docs/VSCODE.md)을 확인하세요.

## 브라우저 시제품 사용하기

**0.5.1:** 브라우저의 **설치·피드백**, VS Code의 **도움말·피드백**에서 내 프로젝트로 넘어가는 안내를 제공합니다. 성공·막힘·미지원 경험을 직접 선택하고, 공유할 요약을 확인한 뒤 복사할 수 있습니다. 자동 전송은 없습니다. [피드백 안내](docs/FEEDBACK.md) · [첫 사용자 5명 관찰 계획](docs/USER_STUDY.md).

미리 빌드한 demo.zip을 풀고 `START.cmd`를 더블클릭하거나 `node scripts/serve.mjs`를 실행하세요. Node.js 24가 필요하며 추가 의존성 설치는 필요 없습니다. 소스에서 시작하려면 `pnpm install --frozen-lockfile`과 `pnpm build`를 먼저 실행합니다. **http://127.0.0.1:4173/?demo=shipping&lang=ko**에서 기존 저장 프로젝트를 건드리지 않는 예제 체험을 제공합니다. 서버 창은 열어 두세요.

1. 처음 보이는 ‘작은 상점’에서 **무료 배송 기준 50,000 → 바꾸기**를 누릅니다.
2. **70000**을 넣고 **변경 미리보기**를 누릅니다.
3. **입력별 결과 비교** 표에서 60000 사례를 추가하고 **변경 전후 비교**를 누르세요. 배송비가 **0 → 3000**으로 바뀝니다. 다른 주문도 함께 비교하고 **비교 설명서 만들기**로 결과를 내보낼 수 있습니다.
4. **이 변경 적용하기**를 누르면 코드와 설명이 함께 갱신됩니다.
5. 변경 기록에서 되돌리거나, **파일 내보내기**로 수정된 파일 ZIP을 받습니다.

‘문장으로 요청’에 **무료 배송 기준을 70000으로 변경**을 써도 같은 변경안을 만들 수 있습니다. 일반적인 앱 생성 요청을 이해하는 AI 채팅은 아닙니다.

## 구현한 기능

아래 목록은 브라우저 시제품의 기능입니다. VS Code 버전은 같은 분석 엔진을 사용하며, 파일 열기·저장·실행 취소를 편집기의 기본 기능에 연결했습니다.

- JavaScript / TypeScript / JSX / TSX / MJS / CJS / MTS / CTS의 구문 분석
- 함수별 입력, 조건, 반복, 반환, 오류 처리의 한국어·영어 설명
- 설명마다 원본 파일·행 번호 연결, 미지원 구문 명시
- **내 프로젝트 용어:** 낯선 변수·함수·입력에 한국어·영어 뜻을 붙이고 그 용어로 규칙 수정. [사용법과 저장 범위](docs/TERMINOLOGY.md)
- 현재 설정값을 바로 보여주는 카드와 데이터·규칙 표
- 정적 상대 경로 import/export 연결 지도, 직접·간접 의존 파일 표시
- 숫자·문자열·불리언·비교 연산의 정확한 범위 수정
- 제한된 문장 요청 → 같은 수정 처리 → 코드 비교 → 명시적 적용
- 문법 검사, 오래된 변경안 차단, 세션 내 역순 되돌리기
- 순수 계산 일부의 입력별 변경 전후 비교와 판단 과정
- 문법 오류·느슨한 비교·비밀값 후보·주변 오류 처리 등 제한된 점검
- 폴더/파일 열기, 브라우저 저장, 읽어 온 파일 ZIP과 Markdown 설명서 내보내기
- 외부 AI/API/분석 서버 없이 로컬 처리, Web Worker와 파일별 재분석 캐시
- 키보드 조작, 기본 대화상자 포커스 관리, 반응형 화면

## 반드시 알아둘 범위

이 버전은 **시니어 개발자의 설계·보안·테스트 판단을 대체하지 않습니다.** 문법이 맞는다는 것과 동작이 맞는다는 것은 다릅니다.

| 항목 | 현재 지원 범위 |
| --- | --- |
| 코드 언어 | JS/TS 계열 상세 분석. JSON은 유효성·개요. Python·CSS·HTML·Markdown 등은 원문 보관/보기만 지원 |
| 사람의 언어 | 한국어·영어. 기본 사전과 사용자가 직접 지정한 파일·선언별 용어 사용. 알려지지 않은 뜻을 지어내지 않음 |
| 수정 | 리터럴 값·비교 연산. 자유로운 기능 생성·여러 파일 리팩터링·새 함수 작성 미지원 |
| 검사 | 구문 파서와 소수의 정적 검토 규칙. 전체 타입 검사·보안 감사·실제 테스트 실행 미지원 |
| 결과 비교 | 제한된 AST 해석기. 숫자/논리/배열/객체 일부, 조건, 반환, 지역 변수, 명시적으로 내보낸 순수 함수 일부 |
| 미리보기 제외 | 네트워크, DOM, 비동기, 반복문, 외부 패키지, 동적 코드 실행, 변경 가능한 전역 상태, 지원하지 않는 초기화 |
| 연결 | 정적 상대 경로 import/export. 동적 import, require, 경로 별칭, 패키지 해석 미지원. 그래프는 40개, 표는 전체 |
| 가져오기 | 파일당 512KB, 전체 8MB, 최대 300개 텍스트 파일. 숨김 파일, `.env`, 의존성/빌드 폴더, 바이너리 등 제외 |
| 내보내기 | **가져온 파일만 포함**. 전체 프로젝트 백업이 아님. 제외된 이미지·설정·의존성 파일은 원래 프로젝트에서 유지해야 함 |
| 저장 | 현재 브라우저·주소의 IndexedDB에 파일·프로젝트 이름·내 용어 저장. 브라우저 데이터 삭제 시 사라짐. 변경 기록은 세션 한정 |

원래 디스크의 코딩 파일은 덮어쓰지 않습니다. 적용은 브라우저 작업 공간에 반영되고, ZIP으로 내보낸 뒤 원하는 프로젝트에 반영합니다. 코드 외부 전송은 없지만 공유 컴퓨터라면 브라우저 저장소에 코드가 남는 점을 고려하세요.

## 개발 및 검증

```sh
pnpm install
pnpm dev       # http://127.0.0.1:5173
pnpm test      # 핵심·경계 조건·증분 분석 테스트
pnpm bench     # 300개 합성 파일의 캐시 성능 측정
pnpm build     # TypeScript 검사 + 프로덕션 빌드
node scripts/serve.mjs # http://127.0.0.1:4173
pnpm extension:build   # 확장 기능 타입 검사 + 번들
pnpm extension:test    # 별도 VS Code 1.96.4에서 실제 통합 테스트
pnpm extension:package # release/pureobom-0.6.0.vsix 생성
pnpm release:package   # 소스·브라우저 체험 ZIP 및 SHA-256 체크섬
pnpm release:check     # 체크섬과 필수 포함 파일 검사
```

TypeScript Compiler API 호환성을 위해 TypeScript 5.9.3을 고정했습니다. 분석기를 Web Worker로 분리해 큰 파서가 UI 번들에 들어가지 않게 했고, ZIP 도구는 내보낼 때 불러옵니다. 변경 없는 파일은 원문 문자열을 비교해 분석 결과를 재사용합니다.
