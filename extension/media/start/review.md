# 무엇을 확인했는지 남기기

변경 파일과 diff, 범위 밖 파일, 검사 파일 변경을 읽으세요. 실패 후 자동 수정을 했다면 이전 검사 회차도 펼쳐 원래 실패를 볼 수 있습니다.

각 완료 기준에 **확인됨·실패·미확인**을 선택하고 관찰한 결과를 적으세요. 실패한 검사 로그도 실패 기준의 근거로 연결할 수 있습니다. 명령 통과만으로 화면 동작까지 확인한 것은 아닙니다.

**검토 기록 저장 → 검토한 변경 반영** 순서로 반영합니다. 실패한 기준이나 검사가 있으면 반영할 수 없습니다. 미확인을 명시적으로 수락하더라도 확인됨으로 바뀌지는 않습니다. 원본이 달라졌으면 이전 결과를 그대로 덮어쓰지 않습니다.

반영 뒤 구조와 관측이 갱신됩니다. **이번 변경 되돌리기**는 코드를 복원하며 설계 목표는 보존합니다.

창을 닫아도 실행은 계속될 수 있습니다. 중지하려면 **작업 취소**를 누르세요. 같은 프로젝트·프로필로 다시 열면 진행 상태에 연결합니다. 관리 프로세스가 사라졌다면 보존된 부분 변경을 검토하고 **이어서 구현**으로 새 작업을 시작합니다. 새 승인과 검사를 거칩니다.

시작 안내의 체크 표시는 안내를 열거나 명령을 실행한 기록입니다. 구현의 실제 완료 여부는 설계 화면의 검토·검사 결과에서 판단하세요.
