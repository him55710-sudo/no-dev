# 내 프로젝트에서 시작하기

VS Code에서 작업할 로컬 JS/TS 프로젝트의 **최상위 폴더**를 열고 **시스템 설계 열기**를 누르세요. 구조 분석에는 모델이나 API 키가 필요하지 않습니다.

왼쪽 트리나 검색에서 파일·함수·규칙을 선택하면 중앙에 관계, 오른쪽에 현재 구현과 원문 근거가 나타납니다. 연결선도 선택할 수 있습니다. 미해석 범위와 추정 관계의 표시를 함께 읽으세요.

**근거 열기**로 실제 코드를 확인하세요. 코드 편집기의 우클릭 메뉴에서 **풀어봄: 선택한 코드를 시스템에서 보기**로 돌아올 수 있습니다.

아직 프로젝트가 없다면 왼쪽의 **예제로 시작하기**로 단일 파일 설명을 체험할 수 있습니다. 그 예제는 전체 시스템 구현 체험과 범위가 다릅니다.

이 개발판의 검증 환경은 데스크톱 VS Code와 로컬 Git 프로젝트입니다. 시스템 설계 화면은 한국어로 제공합니다. VS Code 웹·원격 환경은 검증하지 않았습니다.
