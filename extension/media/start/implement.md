# 구현을 시작할 준비

1. 신뢰한 로컬 Git 저장소의 최상위 폴더를 엽니다. Git에 첫 커밋이 있어야 별도 작업 복사본을 만들 수 있습니다. 처음 Git을 설정하는 프로젝트라면 커밋할 파일부터 검토하세요.
2. 설치한 Codex CLI에서 로그인합니다. 실행기를 찾지 못하면 **실행기 설정 열기**에서 `Pureobom: Codex Path`에 실행 파일 경로를 지정하세요. 모델 설정을 비워 두면 CLI의 설정을 사용합니다.
3. 설계 화면의 **Codex 연결 확인**을 누릅니다. 연결 확인만으로 구현은 시작되지 않습니다.
4. 코드 전달에 동의하고 실제 `package.json`의 검사 명령을 선택합니다. 검사가 없다면 프로젝트에 적합한 테스트·타입 검사부터 준비하세요. 필요하면 선택을 **이 프로젝트에 보관**합니다.
5. 원하는 동작과 완료 기준을 확인하고 **저장하고 구현**을 누릅니다.

작업 패널에 표시된 파일·명령 요청의 범위를 읽고 허용하거나 거절하세요. 에이전트가 끝나면 제품이 선택한 검사를 다시 실행합니다.

설계와 관련 코드는 연결한 모델에 전달됩니다. Git 작업 복사본은 파일 변경을 분리하며 명령 실행을 보안상 격리하지는 않습니다. 이 흐름은 자동 배포나 GitHub 푸시를 하지 않습니다.
