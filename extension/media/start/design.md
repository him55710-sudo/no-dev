# 현재 동작과 원하는 동작 연결하기

관련된 화면·서버 요청·공통 정책을 **업무 기능 만들기**로 묶을 수 있습니다. 이름과 경계는 실제 프로젝트를 보며 정하세요.

오른쪽 설계에서 **원하는 동작**, **유지해야 하는 동작**, **완료 기준**을 작성합니다. 현재 구현의 근거는 별도로 남습니다.

공유 권한이 있는 앱이라면 다음처럼 구체적으로 적을 수 있습니다.

- 원하는 동작: 읽기 전용 멤버는 조회만 가능하며 편집 화면과 직접 수정 요청 모두에서 변경을 막는다.
- 유지할 동작: 소유자와 편집 권한 멤버는 계속 수정할 수 있다.
- 완료 기준: 읽기 전용 멤버의 수정 요청이 거절되고 저장된 데이터가 그대로 남는다.

프로젝트에 없는 역할이나 기능을 이미 있는 것으로 가정하지 마세요.

**설계만 저장**은 명세만 저장합니다. 문구만 다듬을 때는 **설명 다듬기**를 선택하세요. 자동 초안 저장도 구현을 시작하지 않습니다. 실제 코드 변경은 **저장하고 구현**에서 시작합니다.
