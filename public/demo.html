Read the walkthrough영상 내용을 글로 읽기
  1. The source contains a free-shipping threshold of 50,000.
  2. Read source-linked conditions and select the threshold.
  3. Preview a change to 70,000. The exact literal changes; the rest of the function is preserved.
  4. Compare seven inputs. For 60,000, shipping changes from 0 to 3,000. For 70,000, it stays 0.
  5. Apply and inspect 70,000 in the source. Undo restores 50,000.
  6. Install the VS Code extension to try a small change in your own project.
  1. 원본 코드의 무료 배송 기준은 50,000입니다.
  2. 원문에 연결된 조건 설명을 읽고 기준값을 선택합니다.
  3. 70,000으로 바꾸는 변경안을 확인합니다. 선택한 값만 바뀌고 함수의 나머지는 유지됩니다.
  4. 입력 7개를 비교합니다. 60,000 주문은 배송비가 0에서 3,000으로 바뀌고, 70,000 주문은 0을 유지합니다.
  5. 적용한 원문에서 70,000을 확인합니다. 되돌리면 50,000이 복구됩니다.
  6. VS Code에 설치해 내 프로젝트의 작은 변경을 시도합니다.
