# 비개발자 기본 화면으로 방향 수정

2026-10-20 (Asia/Seoul)

## 사용자가 원하는 것

코드·파일·Markdown 형식을 배워서 조작하는 도구가 아니라, 시스템의 하는 일과 바꾸려는 행동을 한국어로 다루는 도구다. 정보의 첫 단위는 파일이나 함수 개수가 아닌 목적과 행동이어야 한다. 이번 변경은 그 방향의 기본 읽기·수정 화면이다.

## 이번에 반영한 범위

- 처음 여는 설명을 ‘쉬운 화면’으로 변경. 기존 상세 도구는 명시적으로 여는 보조 경로다.
- 설명 패널을 활성 편집 영역에서 열어 코드와 양쪽으로 나뉘는 첫 화면을 제거했다. 원문 탭은 보존한다.
- 한국어 1~2문장 요약 → 상세 설명 → 근거 원문의 점진적 구조. 원문과 개발 용어, 연결 설정은 기본 화면에서 감춘다.
- 보내주신 승인 테스트 코드는 직접 검토한 예시로 별도 표시한다. 실제 문서의 자동 분석 결과와 혼동하지 않도록 ‘예제’ 및 ‘자동 해석/실행 결과가 아님’을 표시한다.
- 예제는 시험 환경 확인, 요청 대기, 승인, 세 파일의 문구 교체, 완료/중단을 설명한다. 교체 순서 중 실패하면 앞서 바뀐 파일을 자동으로 복구하지 않는 점도 설명한다.
- 일반 내용은 기존 로컬 AI 연결로 한국어 해석/변경안을 요청할 수 있다. beginner 표현 요청을 시스템 지침에 반영해 요약은 짧게, 조건과 결과는 상세 설명에 남긴다. 원문 근거 검증은 그대로 유지한다.
- 수정 요청은 일반 한국어 입력. 변경 이유와 확인할 점을 읽고 적용한다. 원본 코드 차이 열람은 선택 사항으로 변경했으며, 명시적 검토와 현재 문서/제안 식별 확인은 호스트에서 처리한다.
- 숫자·문구 변경은 기존 실제 파서와 수정 경로를 사용한다. 예시 결과 비교에서 문서 파일 내보내기 버튼을 감춘다.
- 문서 변경이나 입력 변경은 오래된 결과를 무효화한다. 취소는 모델 연결 대기 중에 도착한 결과도 새 추론으로 이어지지 않게 한다.
- 읽기 전용 모드나 AI 연결 실패를 일반 언어로 설명한다. 해당 설정을 임의로 변경하지 않는다.

## 아직 제공하지 않는 것

이 저장소의 새 쉬운 화면은 현재 열어 둔 내용 하나를 대상으로 한다. 여러 파일에 걸친 시스템 동작 변경 및 업무 단위 구조 편집의 완성을 의미하지 않는다. 별도 `codex/system-design-workspace` 작업 트리에는 동시 진행 중인 변경이 있어 수정하거나 합치지 않았다. 그 구조 편집기와 이 화면의 통합은 남아 있다.

검증 환경에는 연결 가능한 로컬 AI가 없었다. 따라서 실제 모델의 한국어 해석 품질이나 임의 코드에 대한 업무 목적 추론 정확도를 검증했다고 주장하지 않는다. 자동 해석과 수정 요청은 연결 가능한 모델이 필요하다. 이번에 추가한 승인 코드 설명은 사람이 검토한 예제이며 자동 AI 처리처럼 표시하지 않는다.

## 검증

- `pnpm extension:build` 통과.
- `pnpm build` 통과.
- `pnpm exec vitest run tests/local-assistant.test.ts`: 15개 통과. beginner 표현 검증 및 없는 근거 인용 거절 포함.
- 실제 VS Code 1.96.4 확장 호스트 통합 시나리오 56개 통과. 새 한국어 변경안 검토에서는 거절/잘못된 변경 개수, 검토 전 적용, 실행 결과 미확인 동의 누락, 오래된 원본을 거절했다. 네이티브 코드 비교 없이 명시적 검토 후 적용·저장하지 않음·한 번의 실행 취소도 확인했다. AI 응답은 통제된 테스트 응답이며 실제 모델 추론은 아니다.
- 통합 검증 뒤 변경한 패널 배치는 설치된 확장의 실제 VS Code 창에서 추가 확인했다. 열린 원본 내용이 선택되고 설명이 전체 편집 영역에 나타났다.
- 설치된 확장에서 ‘쉬운 설명 예제 보기’ → ‘조금 더 자세히 알아보기’ → ‘이 부분을 더 설명해 줘’를 실제 조작했다. 어두운 VS Code 테마에서도 문장과 단계가 표시됐다.
- `release/pureobom-0.7.0-beginner.vsix`로 패키징하고 기본 VS Code 확장 위치에 설치했다.
