# 중단된 변경 이어하기

2026-10-20. 취소되거나 실패한 구현, 관리 프로세스가 종료되어 중단된 구현의 변경을 보존하고 같은 확정 설계로 이어갈 수 있다. 살아 있는 작업에 다시 연결하는 기능은 [창 재연결](MANAGED_AGENT_HOST.md)을 사용한다.

## 사용 흐름

1. 작업 패널 또는 `이전 구현 작업`에서 중단된 작업을 연다.
2. `중단된 변경 이어하기`를 펼쳐 실행 설정과 다시 실행할 검사를 확인한다.
3. `이 변경으로 이어하기`를 선택한다. 현재 남아 있는 변경을 기록한 뒤 새 Git 작업 복사본에 옮긴다. 이전 작업 복사본과 기록은 유지한다.
4. 새 모델 세션이 같은 설계와 부분 변경을 읽고 구현을 계속한다. 필요한 실행 승인은 새 작업에서 다시 받는다.
5. 선택한 검사를 모두 다시 실행하고 새 변경을 검토한다. 검토 후 원본 반영·재분석·되돌리기를 사용할 수 있다. `이전 작업 보기`에서 보존한 변경을 확인할 수 있다.

이는 이전 모델 대화의 내부 상태를 복원하는 기능이 아니다. 새 세션에 확정 설계, 코드 근거, 부분 변경과 이어하기 지침을 전달한다. 이전 승인 ID, 완료 주장, 검사 결과, 사용자 검토 기록은 새 작업의 통과 근거가 되지 않는다. 중단 전 검사 출력은 이전 작업의 참고 기록으로 보존한다.

## 거절 및 복구 조건

- 원본 프로젝트 파일이나 확정 설계가 바뀌면 이어하기를 거절한다. 바뀐 구조와 설계를 확인해 새 구현을 시작해야 한다. 이전 원본과의 자동 병합은 제공하지 않는다.
- 미저장 편집, 오래된 실행 설정, 다른 프로젝트·작업 ID, 코드 전달 선택 누락과 검사 미선택을 거절한다. 관리 프로세스가 여러 창의 요청을 순서대로 처리하며 같은 작업을 중복 시작하지 않는다.
- 원본 반영 기록이 있는 작업은 먼저 기존 파일 복구 흐름을 사용한다. 이어하기로 반영 저널을 우회하지 않는다.
- 부분 변경을 새 작업 복사본에 준비하다 중단되면 그 복사본을 완성된 후보로 취급하지 않는다. 보존된 이전 작업으로 돌아가 다시 이어할 수 있다.
- 이전 작업 복사본을 자동 삭제하지 않는다. 저장 공간 정리 UI와 전원 손실·파일 시스템 장애에 대한 추가 검증은 남아 있다.

설치 검증의 VSIX SHA-256: `3361845dccb2c09c6dc004ba64c5b477bba345ce3dac8df9ba3d9867b82c85b4`. [취소 후 이어하기 설정](evidence/system-workspace/2026-10-20/continuation-cancelled.jpg), [이어하기 후 원본 복원](evidence/system-workspace/2026-10-20/continuation-undone.jpg).

위 설치 검증의 실행기는 결정적 stdio 시험 프로그램이다. 후속 [실제 Codex 이어하기](LIVE_CONTINUATION.md)는 시간 초과로 남은 외부 앱의 일곱 파일을 새 모델 세션에서 이어 구현하고, 독립 검사·전체 Next 빌드·같은 작업의 반영/복원을 확인했다. 최초 검증 드라이버 실패와 복구 결과, 해당 후보의 브라우저 미확인을 별도로 보존한다. 설치 화면은 수정하지 않은 배포 JS/CSS와 실제 Production 확장 호스트를 연결하되 `acquireVsCodeApi` 전송만 로컬 브라우저 검증 경로로 대체한다. 네이티브 VS Code Webview의 포인터 전달 검증은 아니다. 관리 프로세스 강제 종료는 별도 프로세스 회귀에서, 설치 화면에서는 명시적 취소를 확인했다.

시험 프로젝트의 Node 검사는 권한 함수·응답 데이터·403 예외를 확인한다. 실제 화면 렌더러와 HTTP 서버 전체를 검증하지 않으므로 화면 표시 완료 기준 하나를 미확인으로 보존한 채 명시적으로 반영·undo했다. 검토는 검증 에이전트가 작성했으며 사람의 사용성 평가 결과가 아니다.

## 재현

```powershell
pnpm exec vitest run --maxWorkers=1
pnpm build
pnpm extension:build
pnpm extension:design-test
pnpm extension:package
$env:PUREOBOM_DESIGN_UI='1'
$env:PUREOBOM_CONTINUATION_UI='1'
node scripts/test-installed-design-ui.mjs
```

마지막 명령은 독립 임시 프로젝트와 설치 프로필을 만들고 조작할 화면 주소를 출력한다. 위 사용 흐름으로 반영·되돌리기까지 조작한 뒤 `검증 종료·기록 저장`을 눌러야 원본 보존과 이어하기 기록을 검사한다. 실제 모델 실행 모드와 함께 사용하지 않는다.
