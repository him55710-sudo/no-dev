# 선택한 함수의 로컬 설명 · Focused explanations

**0.7 개발판 기능. 공개 안정판과 Pages는 0.6.0이다.** 실제 프로젝트를 읽다가 특정 함수의 역할·입력 조건을 물을 수 있도록 설명 대상을 연결했다. 실제 사용자 프로젝트에서 모델 답변의 정확성이 입증됐다는 뜻은 아니다. [시도별 검증 기록](evidence/local-ai/focused-explanation.md).

## 사용

1. 로컬 VS Code에서 파일을 열고 **이해하기**에서 분석된 함수를 선택한다.
2. **이 기능을 로컬 AI로 설명**을 누르면 AI 도움의 **설명할 범위**에 해당 함수가 선택된다. AI 도움에서 현재 파일 전체 또는 다른 분석된 함수로 바꿀 수도 있다.
3. [Ollama 준비](LOCAL_AI.md)를 마치고 설치된 로컬 모델을 선택한다. 필요한 질문을 적거나 기본 요청으로 실행한다. 버튼을 누르는 것만으로 생성 요청이 자동 전송되지는 않는다.
4. 결과의 함수명·줄 범위와 원문 인용을 확인한다. 기본 요청은 역할·입력·실제로 수행하는 검사와 호출자가 지켜야 할 전제를 구별하도록 한다. 인용을 눌러 편집기의 원문과 대조한다.

현재 파일 전체와 요청·선택한 함수 정보를 보낸다. 원문을 선택 함수와 그 앞뒤로 구분하되, 순서대로 합치면 원래 파일과 문자 단위로 같다. 같은 파일의 보조 함수·상수를 문맥으로 보존한다. 기존 24KB 파일 한도와 합산 프롬프트·180초 제한을 유지한다. 프로젝트 전체·다른 파일은 자동 첨부하지 않는다. 분석된 함수가 없는 파일은 파일 단위 설명만 제공한다. 모델 설치·실행에 필요한 PC 자원은 들지만 유료 AI API로 자동 대체하지 않는다.

## 검증하는 것과 남은 한계

- 화면은 함수 ID만 전달한다. 확장 호스트가 최신 분석 결과에서 이름·원문 범위를 찾고, 없거나 오래된 ID 또는 수정 작업의 함수 선택을 거절한다. 클라이언트가 전달한 임의의 줄 범위를 신뢰하지 않는다.
- 설명 결과에는 선택한 함수 범위와 겹치는 실제 원문 인용이 최소 하나 있어야 한다. 관련 보조 함수의 인용도 가능하지만 다른 함수만 인용한 결과는 거절한다. 원문 문자열의 존재·유일성·범위를 확인하는 검사이며 **설명의 의미·입력 전제·누락 없는 이해를 증명하지 않는다**.
- 설명 요청은 코드 변경을 허용하지 않는다. 함수 선택을 바꾸면 이전 표시 결과를 지우며, 파일 편집·전환 시 기존 요청과 제안은 무효가 된다.
- 한국어·영어 문구와 선택기를 확인했다. 모든 자연어, 프로그래밍 언어의 모든 함수 형태, 실제 모델의 다언어 정확성을 검증한 것은 아니다.
- 일반적인 `total`·`subtotal`·`amount` 이름에 결제·상품·금액을 자동으로 붙이던 기본 용어도 범용 표현으로 바꿨다. 이름 사전은 여전히 문맥 전체를 이해하는 분석기가 아니며 프로젝트별 용어를 직접 지정할 수 있다.

실제 비공개 프로젝트의 첫 두 요청은 각각 180초 시간 초과였다. 이후 [CPU 실행과 선택 원문 구분](evidence/local-ai/focused-context-cpu.md)으로 세 번 완성 응답을 받았으나 잘못된 인용 또는 의미 오류·누락으로 모두 설명 과제에 실패했다. 인용 검사를 통과한 답변에도 의미 오류가 있었다. 현재 판정은 **선택·원문 위치 확인 기능은 검증, 실제 과제의 모델 설명 품질은 부족**이다. 앞서 별도 포매터로 확인한 원래 테스트 8→8→8 및 복구 결과를 모델 설명 성공으로 재분류하지 않는다.

## 개발 재현

`tests/local-assistant.test.ts`는 UTF-16·CRLF 범위와 함수 인용 조건을 검사한다. `extension/test/localAssistant.ts`는 실제 VS Code에서 호스트의 ID 확인·전송 전 거절·원문 이동·편집 후 무효화를 검사한다. 모델 답변은 제어된 HTTP fixture다.

화면만 재현하려면 확장 빌드 후 `node scripts/preview-function-format.mjs --focus`가 표시하는 로컬 주소를 연다. 실제 확장 UI와 분석 worker, 공개 예제를 사용하지만 편집기와 모델 답변은 모의 구현이다. 실제 VS Code 통합 검사·실제 모델 추론과 구분한다.
