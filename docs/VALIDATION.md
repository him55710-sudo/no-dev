# 검증 기록

2026-10-16에 VS Code 확장 기능 검증을 추가했습니다. 엔진·입력 경계 **69개 테스트**와 실제 VS Code **8개 통합 시나리오**를 통과했습니다. 세부 결과는 [VS Code 검증](VSCODE.md)을 참조하세요. 아래는 이전 브라우저 시제품 검증 기록입니다.

검증일: 2026-10-15, Windows / Node.js v24.19.0 / Codex 브라우저.

## 자동 검증

- TypeScript 검사와 프로덕션 빌드 통과.
- Vitest **68개 테스트 통과**: 구문과 원본 위치, JSX, 한국어/영어 편집 요청, JSON, 미지원 언어, import 해석, 정적 검토 후보, 원본 보존, 오래된 Patch 차단, 값 삽입 이스케이프, 경계값 계산, 외부 실행 거부, 재귀 한도, 전역/지역 범위와 초기화 예외, 파일 필터, 증분 캐시.
- 계산 미리보기는 일반 JavaScript 실행기가 아닙니다. 지원하지 않는 부분을 거부하는 경계도 검증했습니다.
- 생산 빌드의 UI JavaScript는 gzip 약 81KB, CSS 약 7.5KB, ZIP 모듈 약 30KB입니다. 분석 Worker는 비압축 약 3.62MB로 분리됩니다.

## 브라우저에서 실제 확인

| 흐름               | 확인 결과                                                                                        |
| ------------------ | ------------------------------------------------------------------------------------------------ |
| 초기 프로젝트      | 5개 파일, 4개 기능, 8개 편집 규칙, 1개 검토 후보 표시                                            |
| 한국어 문장 요청   | ‘무료 배송 기준을 70000으로 변경’ → 50000/70000 차이 표시                                        |
| 계산 비교          | `[60000]` 입력에서 배송비 **변경 전 0 / 변경 후 3000**                                           |
| 카드 직접 수정     | 50,000 카드 선택 → 새 값 입력 → 정확한 동일 코드 변경안                                          |
| 변경 적용          | 카드가 70,000으로 갱신, 4/5 파일 캐시 적중                                                       |
| 되돌리기           | 변경 기록에서 50,000으로 복구                                                                    |
| 지도               | order.ts → shipping.ts / pricing.ts 상대 경로 연결 표시                                          |
| 언어               | 한국어/영어 메뉴·설명·표현 전환                                                                  |
| 모바일             | 390px 설정에서 가로 넘침 발견 후 메뉴 스크롤로 수정. 한국어·영어 페이지 폭과 스크롤 폭 일치 확인 |
| 실제 파일 가져오기 | 직접 만든 policy.ts와 .env를 선택 → policy.ts만 분석, .env 제외 사유 표시                        |
| 가져온 파일 편집   | ‘수량을 3으로 변경’ → 원래 값 2에서 3으로 적용                                                   |
| 내보내기           | 생성된 ZIP을 다시 열어 **policy.ts만 포함**, 실제 파일 내용이 `quantity = 3`인지 확인            |
| 저장 복구          | 새로고침 이후 policy.ts 프로젝트 이름과 수량 3 유지, 세션 기록은 초기화                          |

브라우저 검증은 수동으로 수행한 핵심 경로 검증이며, 모든 브라우저/운영체제/지원 구문 조합을 전수 검증한 것은 아닙니다.

`http://127.0.0.1:4173/`의 최종 프로덕션 빌드에서도 분석 Worker와 0→3000 비교를 확인했습니다. 이 확인 시점의 브라우저 오류·경고 로그는 비어 있었습니다. `preview.png`는 전체 화면, `comparison.png`는 변경 전후 비교의 기록입니다.

## 성능

300개의 작은 합성 파일, 약 36,490문자 기준으로 최근 측정에서 최초 분석 약 233ms, 캐시 분석 약 0.6ms, 한 파일 변경 약 2ms였습니다. 환경과 동시 실행에 따라 달라지며, 최신 원자료는 `benchmark.json`을 확인하세요. Worker 로딩·메시지 전달·UI 렌더링을 제외한 측정입니다.
