# 시스템 설계 개발판의 지원 환경

2026-10-20. 0.7 시스템 설계 워크스페이스 기준이다. 이전 단일 파일 읽기 도구의 언어 지원과 구분한다.

| 대상             | 현재 범위와 근거                                                                                                                                                                     |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 편집기           | 데스크톱 VS Code의 신뢰한 로컬 폴더. 설치 호스트는 VS Code 1.96.4에서 확인. 브라우저 전송으로 설치 번들의 화면 흐름을 확인했으며 네이티브 Webview 포인터 전체 전달은 미검증          |
| 구현 프로젝트    | 첫 커밋이 있는 로컬 Git 저장소 최상위. 실제 package.json의 test/typecheck/check/build 중 사용할 검사가 필요. 기존 staged/unstaged 파일과 변경 중 원본은 보호                         |
| 언어·구조        | TypeScript Compiler API의 JS/TS/JSX/TSX 정적 구조·소스 근거. 업무 기능은 여러 코드 대상과 연결 가능. 미해석 파일은 정밀하게 분석한 것으로 표시하지 않음                              |
| 실제 앱 사례     | 고정 Next.js SaaS Starter의 팀 권한 변경. UI·서버 액션·조회·공통 정책·검사 변경, 실제 PostgreSQL·브라우저 및 별도 전체 빌드 기록. 모든 Next 구성이나 프로젝트의 지원을 보장하지 않음 |
| 실행 환경        | Node.js 24, pnpm 11.25.0으로 개발·검증. 대상 앱의 의존성과 검사 도구는 그 프로젝트에 준비해야 함                                                                                     |
| 모델 연결        | 선택적으로 설치된 Codex App Server 사용. 실제 실행에서 CLI 0.163.0-alpha.10.2 확인. 로그인은 Codex가 관리하며, 구현 시 설계와 코드가 연결된 모델에 전달됨                            |
| Windows          | 실제 모델·설치 호스트·관리 프로세스 재연결·중단 후 새 세션 이어하기·반영/undo 확인. Windows Job Object로 새 실행의 자손 수명 관리                                                    |
| Linux            | Ubuntu CI의 자동 검사와 확장 호스트 검사 통과. 실제 모델·네이티브 화면·Windows와 같은 OS 자손 수명 보장은 별도 미검증                                                                |
| macOS·원격 환경  | 첫 검증 환경에 포함되지 않음. 원격 VS Code, 웹 확장, 컨테이너 환경의 같은 동작을 주장하지 않음                                                                                       |
| 코드와 설계 갱신 | 파일·심볼·해시로 관측을 갱신하고 사용자 목표는 보존. 모호한 재연결과 미확인 목표를 표시. 자연어 목표 전체의 자동 증명은 제공하지 않음                                                |
| 자동화의 끝      | 선택한 검사와 사용자 검토 후 로컬 원본 반영·재분석·undo. 운영 배포·DB 마이그레이션·push가 자동 단계에 포함되지 않음                                                                  |

구조 분석 한도는 최대 500개 파일, 파일당 512KB, 전체 8MB다. 근거 수집과 정적 분석으로 확인할 수 없는 범위는 안내한다. Git worktree는 변경 파일을 분리하며 OS 보안 격리를 대신하지 않는다.

후속 [네이티브 Webview 시작·통신 검사](NATIVE_WEBVIEW_STARTUP.md)는 Windows 설치본의 실제 JavaScript 시작, 호스트 상태 수신 후 캔버스 위치 저장, 닫기·다시 열기와 설계 보존을 확인했다. HTML/CSP·전송 API를 대체하지 않았다. 네이티브 화면의 모양과 포인터·키보드 전체 조작은 여전히 별도 미검증이다.
