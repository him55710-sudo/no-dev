## 대표 과제의 필수 검증

- viewer 조회 허용, 편집 UI 차단, 수정 API 직접 호출 거절 및 데이터 보존.
- editor와 owner 편집 유지, 다른 프로젝트 권한 재사용 거절.
- UI·API·공유 정책·테스트를 한 설계 변경 작업으로 연결.
- 원본이 실행 도중 바뀌면 반영 거절. 취소 뒤 늦은 응답 무효화.
- 일부 반영 실패 시 원본 복구. 검사 도구 누락과 실패를 성공으로 표시하지 않음.
- 자동 초안 저장·관측 갱신·번역은 에이전트를 시작하지 않음.
- 목표와 코드가 달라지면 관측을 갱신하되 목표는 보존.

## 오픈소스 선택

- TypeScript Compiler API (Apache-2.0): 정규식 이름 매칭 대신 실제 심볼·alias·module resolution 사용. 가상 파일 시스템 밖은 읽지 않음.
- React Flow (`@xyflow/react`, MIT): 줌·선택·키보드 탐색·사용자 노드 컴포넌트.
- Dagre (`@dagrejs/dagre`, MIT): 연결 구조의 레이아웃. 노드 이동은 문서/코드를 수정하지 않음.
- Zod (MIT): 파일·Webview 입력의 버전 명시 스키마. 알 수 없는 필드를 거절.
- 기존 React/Vitest/VS Code/Git/Ollama 기반을 유지한다. 외부 에이전트 연결은 기능별 실제 검증 후 지원으로 표시한다.

공식 설계 참고: [Compiler API](https://github.com/microsoft/TypeScript/wiki/Using-the-Compiler-API), [React Flow](https://reactflow.dev/learn), [Zod](https://zod.dev/packages/zod).
