# 공유·권한 구조 분석 예제

Next.js 형태의 경로, React 화면, 서비스, 공통 권한 정책을 연결한 **합성 구조 분석용 소스**다. 배포할 앱이나 실제 인증 구현이 아니다. API의 사용자·데이터는 테스트 상수이며 운영 데이터·네트워크·DB를 사용하지 않는다.

시작 정책은 모든 프로젝트 멤버의 편집을 허용한다. 구현할 목표는 viewer 조회 유지·편집 거절, owner/editor 유지, 다른 프로젝트 권한 재사용 거절이다. 완료에는 실제 UI/API/정책/테스트의 변경과 검사 결과가 필요하며, 구조도가 그려졌다는 것으로 완료를 주장하지 않는다.

VS Code에서 이 폴더를 열고 `풀어봄: 시스템 설계 워크스페이스 열기`를 실행한다. `features → sharing → policy.ts → canEdit`에서 기준선을 확인한다. `components`와 `app/api`에서도 같은 함수를 호출하는 근거를 찾을 수 있다. `풀어봄: 선택한 코드를 시스템에서 보기`로 역방향 탐색한다.
