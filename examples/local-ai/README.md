# 로컬 AI 언어별 검증 예제

`source.html`과 `source.css`는 별도로 추가한 **모델 없는 파서 읽기/수정 예제**다. 아래 모델 평가의 `cases.json`에는 포함하지 않으며 실제 모델 응답 횟수에 더하지 않는다. [지원 범위](../../docs/HTML_CSS_SOURCE.md).

이 파일들은 MIT 라이선스의 작은 합성 예제다. 실제 서비스 프로젝트의 복잡도나 모든 언어 구문을 대표하지 않는다. Python 사례는 상위 폴더의 `shipping.py`를 재사용한다.

| 사례 | 읽을 때 확인할 동작 | 요청한 수정 |
| --- | --- | --- |
| JS/TS, Python, Go, Rust, Java, C# | 음수 주문 금액은 오류, 50000 이상은 배송비 0, 그 외 3000 | 무료 배송 기준만 70000 |
| JSX/TSX | 수량이 정확히 0일 때 주문 버튼 비활성화. 결제 처리 함수는 없음 | 문구만 결제하기 |
| HTML | 필수 수량, 최솟값 1, `/orders`로 POST 제출. 서버 구현은 없음 | 제출 버튼 문구만 결제하기 |
| CSS | 기본 3열·16px 간격, 화면 600px 이하에서 1열 | 기본 4열, 작은 화면 규칙 유지 |
| SQL | paid 주문만 조회, 기준에 따른 배송비 계산 열. 데이터 수정 없음 | 기준만 70000 |
| JSON/JSONC | 설정 데이터. 파일 자체가 배송 계산을 실행하지 않음 | 기준 설정만 70000, 주석 유지 |

`cases.json`은 좁고 명확한 요청과 예상 문자열 변경을 담는다. `node scripts/evaluate-local-languages.mjs qwen2.5-coder:3b 11435 all explain,edit`는 실제 로컬 Ollama에 각 사례를 요청하고, 응답·근거·소요 시간·예상 문자열 일치 여부를 `test-results/`에 기록한다. 클라우드를 끈 로컬 서버와 설치 모델이 필요하다. 이 스크립트는 제안을 적용하거나 실행하지 않는다.

문자열 불일치는 별도 검토가 필요하다는 뜻이다. 예를 들어 Python의 `70_000`과 `70000`은 문자열은 다르지만 같은 숫자다. 일치해도 설명이 맞거나 프로젝트가 정상 동작한다는 증명은 아니다. 모델 문장의 의미, 언어별 문법 검사, 실제 프로젝트 테스트는 별도로 검증한다. 결과를 숨기기 위해 실패 사례를 삭제하거나 성공할 때까지 반복한 결과만 골라 집계하지 않는다.
